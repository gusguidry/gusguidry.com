title: "Colophon"
---

This site is built with [Hugo](https://gohugo.io), a static site generator written in Go. No JavaScript framework. No CMS. No database. Just markdown files and a build step. Search is powered by [Pagefind](https://pagefind.app), which runs entirely at build time — no server required.

The theme is hand-rolled — no template downloaded from the internet, no Bootstrap, no Tailwind. Styles are split across three vanilla CSS files totaling about 1,700 lines. There is a small amount of vanilla JavaScript for copy-to-clipboard, navigation, and an automatic citation generator (APA, MLA, Chicago) that exists mainly so I can mock the people who demand one.

Both display and body type are Garamond: [Cormorant Garamond](https://fonts.google.com/specimen/Cormorant+Garamond) for headings and the masthead, [EB Garamond](https://fonts.google.com/specimen/EB+Garamond) for running text, both served from Google Fonts. True small caps and old-style figures throughout, a drop cap opening every post, footnotes marked with typographic daggers instead of digits. Code is highlighted with Pygments' "friendly" theme by day and [Gruvbox](https://github.com/morhetz/gruvbox) at night. Dark mode follows your system preference or a manual toggle.

The site participates in the [IndieWeb](https://indieweb.org). Webmentions are handled by [webmention.io](https://webmention.io).

The source lives on [GitHub](https://github.com/gusguidry). It is licensed however I feel like at the time you're reading this.

The site is hosted statically. It does not track you. There are no cookies, no analytics, no ad network. If something breaks, I probably broke it.

*A colophon is the note at the back of old books describing how they were made. This is that.*
