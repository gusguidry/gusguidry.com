# gusguidry.com

The personal site of Gus Guidry: essays, opinions, and the occasional recipe, in English and Japanese.

Built with [Hugo](https://gohugo.io), searchable with [Pagefind](https://pagefind.app), and deployed to GitHub Pages on every push to `master`.

## Running it locally

```sh
bun install       # installs Pagefind
bun run dev       # builds once, indexes search, starts the preview at localhost:1313
```

`bun run build` produces the production site in `public/`.

## Found a mistake?

Every page has a link to its source file. Patches are welcome; opinions are negotiable.
